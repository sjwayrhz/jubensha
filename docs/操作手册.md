# jubensha 操作手册

面向非技术人员：管理员、DM、玩家三类角色的操作步骤。界面按钮名称以实际页面为准。

---

## 一、管理员篇

### 1. 登录后台

- 打开网站，点「登录」，用管理员邮箱登录。
- 登录后顶部导航会出现「剧本管理」「用户管理」入口（普通玩家看不到）。
- ⚠️ 测试账号 `admin@jubensha.local` / `admin123` 仅用于测试，**正式上线前必须改密码**。

### 2. 上传 PDF 剧本

1. 进「剧本管理」→「上传剧本 PDF」，选择 PDF 文件上传。
2. 上传后剧本出现在「剧本库」列表，状态为"已上传"。

### 3. 触发解析

- 在剧本库中找到该剧本，点「解析」。
- 文字版 PDF 直接提取文字；扫描版 PDF 自动走 OCR 识别。解析完成后会显示解析方式和字数。

### 4. 校对原文

1. 点「校对」，在文本框里检查、修改识别出的文字（OCR 难免有错别字，重点检查人名、地名）。
2. 点「保存校对」。
3. **真凶标记**：请在文本中注明真凶（例如写明"真凶：管家"），并在结构化后确认真凶已正确标记——公布真相时若未标记真凶会报错。

### 5. 结构化并发布

- 校对无误后点「结构化并发布」。系统按规则拆出人物、线索，剧本状态变为"已发布"，玩家端即可看到。

### 6. 用户管理与开通 DM 权限

1. 进「用户管理」，看到所有注册用户列表。
2. DM 只用熟人、邀请制：找到该熟人的账号，把角色从 `player` 改为 `dm`，保存即开通。
3. 不要随意给陌生人开 DM 或管理员权限。

## 二、DM 篇

### 1. 建房

1. 用 DM 账号登录，进「DM」→「新建房间」。
2. 下拉选择已发布的剧本，点「建房」。
3. 建房成功后页面显示 **6 位房间码**，把房间码发给玩家（微信/群里发）。

### 2. 开始游戏

- 玩家到齐后，在房间控制台点「开始游戏」，进入选角阶段。

### 3. 分配角色

- 在「分配角色」卡片：左边下拉选玩家，右边下拉选角色，点「分配」。
- 每个角色只能分给一个人，分配完进入下一步。

### 4. 按阶段推进

控制台会显示当前阶段（等待→选角→读本→搜证→讨论→投票→复盘→结束），点「下一步：XXX」按顺序推进：

| 阶段 | 玩家在做什么 | DM 要做什么 |
|---|---|---|
| 选角 | 等待分配 | 分配角色后点下一步 |
| 读本 | 各自看自己的剧本 | 等待，可点下一步 |
| 搜证 | 查看已投放的线索 | 用「投放线索」发线索 |
| 讨论 | 文字聊天、发语音条 | 控场，可点下一步 |
| 投票 | 投票指凶 | 点「开启投票」，收齐后点「关闭投票」 |
| 复盘 | 看真相 | 点「公布真相」 |

### 5. 投放线索（公开 / 定向）

- 在「投放线索」卡片选一条线索：
  - **公开（全体可见）**：所有玩家都能看到，如现场证据；
  - **定向（指定玩家）**：只选"定向"，再选一名玩家，只有他能看到，如个人线索。
- 点「投放」即时生效，玩家屏幕上会实时收到。

### 6. 开关投票

- 讨论差不多时点「开启投票」，玩家开始投票（一人一票，不能投自己）。
- 票数收齐（或时间到）点「关闭投票」，自动进入复盘阶段。

### 7. 公布真相

- 在复盘阶段点「公布真相」，系统公布真凶与复盘文本，本局结束。
- ⚠️ 若剧本没标记真凶，这一步会报错——开局前请确认剧本已正确标记（见管理员篇第 4 步）。

## 三、玩家篇

### 1. 注册登录

- 打开网站，点「注册」，用**邮箱**注册（不需要手机号、不收短信验证码），设好昵称和密码后自动登录。

### 2. 加入房间

- 首页输入 DM 给你的 **6 位房间码**（不区分大小写），点加入。
- 进房后在等待区看到其他玩家，等 DM 开始游戏。

### 3. 各阶段能看到什么、能做什么

- **选角**：等待 DM 分配角色；分到角色后会显示角色名。
- **读本**：只能看到**自己的角色剧本**，看不到别人的。
- **搜证**：查看线索列表。公开线索大家都能看；定向线索只有被指定的你能看到。
- **讨论**：发文字消息，或点「🎙 录语音条」录一段发出去（手机浏览器直接录音）；也能播放别人的语音条。
- **投票**：选一名玩家指认为凶手并提交。**一人一票，不能投自己**，提交后不可更改。
- **复盘/结束**：查看真凶、完整真相与复盘。

### 4. 实时更新

- DM 的操作（切阶段、投线索、开关投票）会实时推送到你的屏幕，不用手动刷新；断网重连后自动恢复。

## 四、常见问题

1. **收不到验证码？**
   本系统是邮箱+密码注册，没有短信验证码。如果注册时提示"该邮箱已注册"，直接去登录。

2. **进不了房间？**
   先核对 6 位房间码是否输错；如果房间已经开始（过了等待阶段），新玩家进不去，联系 DM。

3. **语音条发不出？**
   语音只支持 mp3 / m4a / wav / amr / webm 格式，且**不超过 2MB**。手机浏览器点「🎙 录语音条」按提示允许麦克风权限。

4. **DM 误操作切错了阶段怎么办？**
   阶段只能向前不能后退，DM 自己改不回来。请联系管理员处理。

5. **投票投错了能改吗？**
   不能，一人一票、提交即锁定，投票前想清楚。

6. **忘记密码怎么办？**
   目前没有自助找回功能，联系管理员重置。
