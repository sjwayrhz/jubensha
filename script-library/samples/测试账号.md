## 重要：必须用两个不同的浏览器

DM 和玩家**不能**在同一个浏览器里登录——登录状态存在浏览器的 localStorage 里，同一个浏览器后登录的账号会覆盖先登录的，看起来就像"被踢下线"。

可行方案（三选一）：
1. 电脑 Chrome 登 DM，手机 Safari/Chrome 登玩家（推荐，最接近真实场景）；
2. 电脑上用两个不同的浏览器（如 Chrome + Edge）；
3. Chrome 右上角头像 → 添加用户，开两个用户配置；
4. Firefox 开两个隐私窗口（每个窗口存储独立）。

注意：Chrome/Edge 的多个匿名窗口共享同一份存储，不行。

## 单人测试流程

### 1. DM 建房（DM 浏览器）
1. 用 `test-dm@hxsn.eu.cc` 登录，进 DM 控制台。
2. 选剧本《山庄迷雾-单人版》，点建房。
3. 拿到 6 位房间码（记下来，给"玩家"用）。

### 2. 玩家加入（玩家浏览器）
4. 用 `test-solo@hxsn.eu.cc` 登录。
5. 首页输入房间码，加入房间，等待 DM 开始。

### 3. 开局（DM 浏览器）
6. 点"开始游戏"，进入选角阶段。
7. 分配角色：把"侦探林"分配给测试玩家。
   - "管家陈"是 NPC（真凶），**不要**分配给玩家，复盘时由 DM 揭晓。

### 4. 走流程（DM 推进，玩家体验）
8. 读本：玩家只能看到侦探林的剧本。
9. 搜证：DM 投放线索（4 条都是公开线索）。
10. 讨论：玩家发文字/语音条（自言自语也行，测功能）。
11. 投票（指认真凶）：玩家端会列出侦探林、管家陈两个选项，点"指认"选出你心中的真凶（一次，不可改）。
12. DM 推进到真相复盘：揭晓真凶，并显示你的指认是否正确。
12. 复盘：DM 公布真相——真凶是管家陈。

### 5. 要验证的点
- DM 建房页能看到已发布剧本（之前修过一个 DM 看不到剧本的 bug）。
- 玩家端各阶段页面在手机/电脑上显示正常。
- WebSocket 实时同步（DM 切阶段，玩家端自动刷新）。
- 语音条录制/播放正常。
