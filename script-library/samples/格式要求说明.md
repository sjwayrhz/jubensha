# 剧本库格式要求说明

剧本库只收 **TXT** 文本（不收 PDF/Word/图片）。一个剧本需要准备两份东西：

## 一、玩家剧本（每位玩家一份，拼成一个 TXT 上传）

### 1. 文件头（整个文件开头只写一次）

```
剧本标题
X人本，约XX分钟。

简介
一两句故事梗概（剧本列表里展示给玩家的）。
```

- 标题：第一行就是标题。
- `X人本`：写明人数，如 `1人本`、`4人本`、`6-8人本`。系统据此识别人数范围。
- 时长：如 `约30分钟`、`约3小时`。

### 2. 人物（每位玩家一段，含 NPC）

```
人物
侦探林：你。今晚的真相，由你亲手揭开。
管家陈：山庄管家，在庄里工作了二十年。（NPC，真凶，由 DM 在复盘时揭晓，不要分配给玩家）
```

- `人物` 独占一行作为小节标题。
- 每行格式：`姓名：简介`（中文冒号），姓名不超过 12 字，简介至少 4 字。
- 简介 = 玩家在**选角界面**看到的人物介绍 + 读本内容，写清楚、写吸引人。
- NPC 也要列出来，并在简介里备注 `（NPC……）`，DM 就知道不分配。
- 凶手不要在简介里暴露！只备注 NPC 身份。

### 3. 线索

```
线索
线索1：书房地毯下发现带血的匕首，刀柄上有指纹。
线索2：管家房里藏着一瓶安眠药，与死者茶杯残留一致。
```

- `线索` 独占一行作为小节标题。
- 每行格式：`线索N：内容`。
- DM 可在控场时选择公开投放或定向投放给某位玩家。

### 4. 真相（文件末尾）

```
真相
真凶：管家陈
管家陈在茶里下了安眠药……（复盘正文）
```

- `真相` 独占一行作为小节标题，之后的内容不再被当作线索。
- `真凶：姓名`：姓名必须和"人物"里的某个人物**完全一致**，系统据此标记真凶、做复盘揭晓和指认判定。
- 后面写复盘正文，真相揭晓时展示。

### 完整示例

见本目录 `山庄迷雾-单人版.txt`（单人本完整示例）和 `玩家剧本-模板.txt`（单人份剧本写法）。

## 二、DM 手册（单独一份，不上传，在剧本管理里粘贴）

- 格式见本目录 `DM手册-模板.txt`。
- 内容：开场白、时间轴、真凶与手法、线索投放指南、复盘要点、常见问题。
- **仅 DM 可见**：DM 在控场台点"DM 手册"查看，玩家端永远不会出现。
- 添加方式：剧本管理 → 找到剧本 → 点"DM手册" → 粘贴保存。

## 三、通用要求

1. 只收 TXT，UTF-8 编码，不要带奇怪符号。
2. 标点用中文标点；冒号用中文冒号 `：`。
3. 小节标题（`简介`/`人物`/`线索`/`真相`）必须独占一行、顶格写。
4. 来源、作者/发布方、免费或授权说明必填（见上级 README），无来源不发布。
5. 解析后必须人工校对，结构化发布前检查真凶标记是否正确。
