# 剧本库（script-library）

本目录是 jubensha 的剧本资产库：样例剧本、上传规范，以及所有经网页上传的剧本 PDF（原文件名保留）。

```
script-library/
├── README.md      # 本说明 + 上传要求
├── samples/       # 样例剧本（随仓库发布）
└── uploads/       # 网页上传的剧本 PDF（原文件名保留，随仓库提交）
```

## 上传剧本的要求

1. **格式**：只收 PDF。文字版直接提取，扫描版走 OCR；Word / TXT / 图片请先转成 PDF 再传。单个文件 ≤ 50MB。
2. **来源必填**：每个剧本必须记录原始链接、作者 / 发布方，以及免费分享或授权说明。**无来源不发布**；盗版流出的付费本不上架。公开运营或商业使用前，逐个复核授权范围。
3. **人数与时长**：建议 4–8 人本；请注明预计时长（如"约 90 分钟"），方便 DM 选本。
4. **校对不可跳过**：上传后必须走「解析 → 人工校对 → 结构化 → 发布」全流程。OCR 对中文有误识，校对是最后一道关。
5. **结构化格式规范**（校对文本请按此排版，系统按规则自动拆分）：
   - 章节标题单独成行：`人物` / `线索` / `真相`（另可加 `简介` / `复盘`）
   - 人物行：`姓名：简介`（例：`林夫人：死者的妻子，昨晚曾与丈夫大吵一架。`）
   - 线索行：`线索1：内容`（例：`线索1：书房地毯下发现一把带血的匕首。`）
   - 真相章节写：`真凶：姓名`（例：`真凶：管家陈`），系统据此自动标记真凶
   - 标题取第一行；人数写如 `4人本` 或 `4-6人`
6. **文件存放**：网页上传的 PDF 保存在 `script-library/uploads/`，文件名=清洗后的原文件名 + 8 位随机串（如 `午夜山庄_a1b2c3d4.pdf`），随仓库提交入库。

## 样例

`samples/午夜山庄-样例.pdf`：4 人新手推理本（人物 / 线索 / 真相复盘俱全），同目录另有同名 `.txt` 校对文本可对照。想快速体验开本流程，直接用它发布即可。
